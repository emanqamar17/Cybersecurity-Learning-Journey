# Day 17 — Linux File Viewing Commands

## Objective

Learn how to view and inspect file contents using Linux.

---

## Commands Practiced

### cat

Displays file contents.

```bash
cat test.txt
```

---

### head

Displays first lines of a file.

```bash
head test.txt
```

---

### tail

Displays last lines of a file.

```bash
tail test.txt
```

---

### less

Views large files page by page.

```bash
less test.txt
```

---

## Practical Exercise

```bash
echo "Cybersecurity" > test.txt

cat test.txt

head test.txt

tail test.txt
```

---

## Learning Outcome

Learned how to:

- Read files
- Inspect content
- View large files efficiently

---

## Why This Matters

Security professionals often analyze:

- Log files
- Configuration files
- System outputs
- Evidence files

These commands are frequently used during security assessments.
