## Objective

Learn basic Linux file and directory management commands.

---

---

## Commands Practiced

### touch

Create a file.

```bash
touch test.txt
```

---

### mkdir

Create a directory.

```bash
mkdir day16
```

---

### rm

Delete a file.

```bash
rm test.txt
```

---

### rmdir

Delete an empty directory.

```bash
rmdir day16
```

---

### cp

Copy files.

```bash
cp file1.txt file2.txt
```

---

### mv

Move or rename files.

```bash
mv file1.txt renamed.txt
```

---

## Practical Exercise

Executed:

```bash
mkdir day16

cd day16

touch test.txt

cp test.txt copy.txt

mv copy.txt renamed.txt

ls

rm renamed.txt

ls
```
