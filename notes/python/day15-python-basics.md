## Key Python Concepts Learned

### print()

Displays information on the screen.

Example:

```python
print("Hello")
```

---

### Variables

Store information.

Example:

```python
name = "Test"
```

---

### input()

Accepts user input.

Example:

```python
name = input("Enter your name: ")
```
