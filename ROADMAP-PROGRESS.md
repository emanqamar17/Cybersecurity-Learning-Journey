# Current Security Mindset

For every vulnerability I am training myself to ask:

1. What is happening?
2. Why does this functionality exist?
3. How does it normally work?
4. What can the attacker control?
5. What does the application trust?
6. What trust assumption failed?
7. Where is the trust boundary?
8. What is the realistic impact?
9. How would a Pentester discover it?
10. How would an AppSec Engineer prevent it?
11. How would a developer fix it securely?
